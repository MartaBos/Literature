The online pages are updated whenever the repository is pushed. Comments are read-only online; they are edited through the notes server on abacus2.

- `notes/`: notes per paper (JSON), `catalog.json` (subcategories, links, tags), `comments.json` (my comments)
- `notes_builder/`: scripts, template and the full documentation (`notes_builder/README.md`)

PDFs, paper text files, downloads, logs and the notes-server key are not in this repository (`.gitignore`).
