# Literature: paper notes

Flashcard-style notes pages for my literature, one page per folder:

| Page | File |
|---|---|
| Astyanax mexicanus | `papers/amexicanus/paper_notes_amexicanus.html` |
| Danio rerio | `papers/drerio/paper_notes_drerio.html` |
| General | `papers/general/paper_notes_general.html` |
| Regulatory genomics | `papers/regulatiory_genomics/paper_notes_regulatiory_genomics.html` |
| Signaling pathways | `papers/signaling/paper_notes_signaling.html` |

To read a page from GitHub: open the file → *Download raw file* → open it in a browser.

- `notes/`: notes per paper (JSON), `catalog.json` (subcategories, links, tags), `comments.json` (my comments)
- `notes_builder/`: scripts, template and the full documentation (`notes_builder/README.md`)

PDFs, paper text files, downloads, logs and the notes-server key are not in this repository (`.gitignore`).
